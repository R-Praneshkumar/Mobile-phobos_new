# Flutter Dashboard UI

A multi-screen Flutter application designed to provide a pixel-perfect UI based on a set of HTML design references. The application showcases a dashboard, leave balance, leave history, and a user profile screen.

## Project Overview

This application is built with Flutter and demonstrates a clean, well-structured approach to building beautiful and functional user interfaces. It is an ideal starting point for anyone looking to understand how to translate a design into a fully functional Flutter app.

The app consists of four main screens:
-   **Dashboard:** An overview screen with quick stats and recent activity.
-   **Leave Balance:** A detailed breakdown of leave balances with progress indicators.
-   **Leave History:** A filterable list of leave requests with status indicators.
-   **Profile:** A user profile screen with settings and support options.

## Prerequisites

Before you can run this application, you will need to have the Flutter SDK installed on your machine. If you are new to Flutter, you can follow the official guide to get started.

-   **Install Flutter:** [Official Flutter Installation Guide](https://docs.flutter.dev/get-started/install)

Make sure you have an editor configured for Flutter development (e.g., VS Code with the Flutter extension or Android Studio) and that you can run a Flutter app on an emulator, simulator, or a physical device.

## Getting Started

Follow these steps to get the application up and running on your local machine.

### 1. Clone the Repository

First, clone this repository to your local machine using your preferred method (HTTPS or SSH).

```bash
git clone <repository-url>
```

### 2. Navigate to the Project Directory

Once the repository is cloned, navigate into the project directory.

```bash
cd app
```

### 3. Install Dependencies

With Flutter installed, you can now install the project's dependencies by running the following command in the `app` directory. This will download all the necessary packages defined in the `pubspec.yaml` file.

```bash
flutter pub get
```

### 4. Run the Application

You are now ready to run the application. You can run it on an emulator, a simulator, or a connected physical device. Make sure you have a device running before executing the command.

To run the app, use the following command:

```bash
flutter run
```

The application will build and launch on your selected device. You can interact with the UI, navigate between screens, and explore the pixel-perfect design.

### Hot Reload

Flutter's hot reload feature allows you to see your changes almost instantly without restarting the app. To use hot reload, simply save your changes in your editor, or press `r` in the terminal where the app is running.
